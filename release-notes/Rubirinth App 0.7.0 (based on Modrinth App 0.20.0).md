### Что нового в Rubirinth 0.7.0:
* Обновлена кодовая база до версии Modrinth App 0.20.0.
* Добавлена автоматическая установка зависимостей CurseForge:
  * При установке мода с CurseForge теперь проверяется список обязательных зависимостей (`dependencies`) в метаданных файла и предлагается/выполняется автоматическая установка совместимых модов-библиотек в 1 клик (как это работает для Modrinth).
  * Реализована фильтрация файлов зависимостей CurseForge по версии Minecraft и загрузчику (Fabric, Forge, NeoForge, Quilt), что гарантирует подбор совместимой версии библиотеки даже для старых версий игры.
  * Добавлено умное сопоставление Fabric API: предотвращена установка дубликата Fabric API на Quilt-сборках, а также при одновременном использовании модов с CurseForge и Modrinth.
* Добавлено получение и отображение списка изменений (changelog) для файлов и сборок CurseForge: список изменений теперь корректно загружается и отображается как в окне смены версии сборки, так и на странице отдельной версии.
* Добавлена проверка и массовое обновление модов с CurseForge:
  * Реализован автоматический фоновый запрос к API CurseForge (get_files) для проверки новых версий модов с учётом версии игры, загрузчика и канала стабильности.
  * Для модов с CurseForge теперь отображается значок доступного обновления и работает кнопка «Обновить всё» (Update all), позволяющая обновить все устаревшие моды в один клик.
  * Поддерживается индивидуальное обновление модов с CurseForge и массовое обновление через выбор чекбоксами в списке файлов сборки.
* Улучшена и дополнена русская локализация:
  * Полностью переведена новая вкладка настроек «Функции» (Features) и все новые параметры Modrinth 0.20.0.
  * Переведены заголовки столбцов таблицы в списке версий проекта (Версия, Версия игры, Платформа, Окружение, Опубликовано, Скачивания).
  * Исправлена проблема, из-за которой приложение могло открываться на английском языке при выбранной русской локали.

### Изменения Modrinth (0.20.0):
* Добавлена синхронизация и редактирование файлов `options.txt`: настройки графики, звука, управления и доступности теперь можно синхронизировать между сборками.
* Добавлена опциональная синхронизация ресурспаков: общий доступ к ресурспакам, их порядку загрузки и активности между совместимыми сборками.
* Добавлены индивидуальные настройки синхронизации: возможность выборочно отключать синхронизацию параметров для конкретных сборок.
* Добавлена новая вкладка настроек «Функции» (Features):
  * Централизованное управление видимостью вкладок (Файлы, Миры, Скриншоты) сразу для всех сборок.
  * Переключатель отображения селектора скинов в боковой панели.
  * Настройка лимита карточек сборок в блоке быстрого запуска.
* Значительная оптимизация памяти и производительности:
  * Существенно снижено потребление оперативной памяти при старте, в простое и при открытии больших библиотек сборок.
  * Устранены утечки памяти при навигации по разделам лаунчера.
  * Оптимизировано использование памяти при установке Minecraft, модпаков и обновлении контента.
* Обновлен встроенный редактор скриншотов: системный диалог выбора цвета заменен на стилизованный color picker.
* Исправлены рывки и некорректные анимации карточек сборок при масштабировании и прокрутке библиотеки.
